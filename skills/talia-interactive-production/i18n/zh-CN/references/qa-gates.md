# 质检门槛

## 图片门槛

出现以下问题必须拒绝并重做：身份、年龄、五官肢体、材质、轮廓、服装或标志错误；偏离已验收定妆照；缺失、重复或融合部件；接触、视线、尺度或空间不可能；剧情状态错误；出现禁止人物、道具、变身、文字、水印、边框或 UI；互动目标不可用。

背景小差异只有在不影响剧情、连续性、身份、互动和后续制作时才可以通过。

## 视频门槛

检查首帧、尾帧、每次动作转换和说话人变化，以及容易出现遮挡、水线折射、接触、变身和快速运动的时间段。检查身份、动作因果与方向、意外切镜/冻结/倒放/克隆/文字/UI、准确对白、语言、说话顺序、口型、环境声、BGM 规则和音轨是否存在。

接触表用于快速扫描；疑似问题要抽取全分辨率定点帧。接触表不能验证快速变形或准确对白。

## 节点成片门槛

验证画面尺寸和方向、编码、可播放时长、必要音轨、规范采样率和声道、没有意外截断或黑尾、文件名和节点映射正确。

## Talia 草稿门槛

验证开始节点、选项目标存在、结局可达、所有可达非结局节点有出口、媒体 URL、自动推进规则、Tap Region 不重叠且对应可见目标、标题/封面/语言/样式，以及 CLI 验证结果。

CLI 修改成功不代表体验正确。手动发布前要预览每条路线。
