# 能力路由

模型影响推理、叙事、视觉理解和工具调用质量；harness 决定是否能接触本地文件、图片、视频、音频、Shell、浏览器、登录态和生成工具。不能根据模型品牌推断能力。

| 能力 | 必须取得的证据 | 缺失时的路线 |
|---|---|---|
| 文件 | 创建并重新读取临时文本 | 只输出文字交接 |
| Shell | 运行无副作用的版本命令 | 跳过确定性脚本 |
| 识图 | 查看真实图片并说出可验证细节 | 视觉质检标记 `unverified` |
| 生图 | 用已配置工具生成一次临时测试图 | 准备自包含生图工单 |
| 视频审核 | 直接理解视频，或抽帧后识图 | 动态质检标记 `unverified` |
| 音频审核 | 播放/转录并检查音轨 | 只验证音轨技术事实 |
| 浏览器 | 打开、检查、点击、输入并上传临时文件 | 准备网页操作说明 |
| Talia CLI | `whoami`、项目列表和验证 | 准备变更清单 |
| 持久登录 | 新进程中重复只读请求 | 由创作者执行登录操作 |

`scripts/capability_probe.py` 可以探测本地程序，但不能证明识图、浏览器上传、账号权限或付费服务访问；这些能力必须单独测试。

## 路线

- **图片：**内置生图 → 已配置 API → 创作者选定且已登录的网站 → 自包含生图工单。
- **视频：**使用创作者指定的供应商。Talia 付费生成始终手动执行。远程任务显示完成后仍须下载并通过 G3。
- **视频质检：**优先直接理解视频；否则生成接触表和定点全分辨率帧，并单独检查音频。没有识图能力时只能验证技术参数。
- **浏览器：**文件上传必须与点击、输入分开测试。无法完成上传的浏览器 harness 不是完整生产路线。
