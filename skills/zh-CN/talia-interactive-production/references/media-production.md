# 媒体制作

## 锚点

在制作依赖图片前验收不可变的角色定妆照，记录五官肢体、年龄和比例、脸、轮廓、材质、颜色、服装、标志和禁止特征。场景锚点规定布局、入口、地标、光线方向和尺度。

每次生图都保留原始身份锚点。生成镜头和抽取的真实尾帧可以补充构图或时间连续性，但不能取代原始锚点。

## 图片工单

写明资产 ID 和输出路径、剧情用途、画幅和风格、编号参考及其作用、身份不可变量、构图/动作/摄影机/光线/环境、道具和空间关系、禁止内容/文字/水印/UI，以及验收清单。

每张结果使用前必须审核。验收图保存到项目目录。硬条件失败时，从原始锚点出发进行定向重做。

## 视频工单

写明起始状态、按顺序发生的动作、结束状态、摄影机、身份不可变量、对白、说话人、声音意图、环境声、禁止音频、时长、画幅、分辨率、参考模式和验收清单。短视频包含太多独立动作或地点时应拆镜。

- `First Frame`：已验收首帧已经规定起始状态。
- `First + Last`：需要控制两个端点。
- `Omni`：需要额外的身份、场景、道具或风格参考。

对白审核包括准确文本、语言、说话人、顺序、时间和口型。画外音或无嘴角色可以较安全地替换音轨；画面中清楚说话的嘴应保留原生同步音频或重做。

按项目交付参数规范化已验收节点成片。记录供应商、模型、模式、时长、实际费用、任务 ID、URL、本地路径、提示词、参考顺序、质检和应用节点。使用前重新确认当前价格和模型可用性。
