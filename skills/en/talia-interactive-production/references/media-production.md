# Media production

## Anchors

Approve immutable identity sheets before dependent images. Record anatomy, age/proportion, face, silhouette, material, color, costume, markings, and forbidden traits. Environment anchors establish layout, entrances, landmarks, light direction, and scale.

Every generated image retains the original identity anchors. Generated shots and extracted tail frames may add composition or timing but never replace those anchors.

## Image order

Specify asset ID/output path, story purpose, ratio/style, numbered references and their roles, identity invariants, composition/action/camera/light/environment, props and spatial relationships, forbidden content/text/watermark/UI, and acceptance checks.

Inspect every result before use. Save accepted outputs inside the project. When a hard criterion fails, regenerate from the anchors with a targeted correction.

## Video order

Specify start state, ordered action beats, end state, camera, identity invariants, dialogue, speaker, vocal intent, ambience, forbidden audio, duration, ratio, resolution, reference mode, and acceptance checks. Split a short clip that contains too many independent actions or locations.

- `First Frame`: the approved frame already specifies the start.
- `First + Last`: both endpoints require control.
- `Omni`: extra identity, environment, prop, or style references are necessary.

Review dialogue for exact words, language, speaker, order, timing, and mouth movement. Replacing audio is low-risk for voice-over and mouthless speakers. For visible speaking mouths, preserve native synchronized audio or regenerate.

Normalize accepted node masters to the project delivery profile. Record provider, model, mode, duration, actual cost, job ID, URL, local path, prompt, reference order, QA, and applied node. Recheck current prices and model availability at use time.
